# Architecture Decision Records (ADR)

> Preserved architectural knowledge for the CloudForge platform.

## Format

All ADRs follow the template at [templates/adr-template.md](../../templates/adr-template.md).

## Naming

```
NNN-short-description.md
```

Examples:
- `001-multi-repo-vs-mono-repo.md`
- `042-api-gateway-selection.md`

## Status

- 🔄 **Proposed** — Under discussion
- ✅ **Approved** — Accepted and implemented
- ❌ **Rejected** — Considered but not accepted
- 🗃️ **Superseded** — Replaced by a newer ADR

## Contributing

To propose a new ADR:
1. Open a GitHub Discussion
2. Create an RFC if needed
3. Submit PR with ADR using the template
4. Architecture Board reviews and approves
